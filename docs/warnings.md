# Warnings

Read these before using Stemma.

## Debugging port

Stemma needs the launch option `--remote-debugging-port=9222`. While it is set, **any program on your PC** can control the game through that port; nothing outside your PC can. Remove it from the launch options when you are not using Stemma.

## Steam achievements

With "Also unlock on Steam" on (the default), these unlock on Steam:

- the achievements Stemma marks;
- those of the traits it adds (crowns, wounds, *Veteran*, *Pedigreed*…);
- those given by a forced outcome in military events.

**Steam achievements cannot be removed.** If you don't want that, turn off the checkbox in the Achievements section.

Like the game, nothing is sent in easy mode, sandbox mode or with mods.

## Backups

Back up your saves before big changes. They are in:

```
Documents\CitizenOfRomeDynastyAscendant\saves
```

Some changes cannot be undone, such as forcing a character's death or, in the Extras section: giving up for adoption, divorcing and playing a scenario.

## Mod mode

Stemma **does not turn on the game's mod mode**, which is what disables a save's achievements. The options in the Extras section do the same as the game's example mods, but they use the game's functions the way the game itself uses them, without turning mods on, so achievements stay active.

## Game version

Tested with version **1.6.37**. If an update changes something, the affected section shows "Not available" and the rest keeps working.
